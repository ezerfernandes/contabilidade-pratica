Get started

Your first scene in a few minutes

Install the skill once, describe what you want explained, and your agent writes the scene, checks it frame by frame and adds it to your page.

01Install the skill

It works with Claude Code, Codex and other agents that support skills.

$npx skills add nilbuild/stick-scene

02Ask for a scene

Say what it should explain and where it goes. Be as broad or as specific as you like. It will pitch two or three ideas for you to pick from.

03Ask for changes

If something looks off, say what's wrong and it re-draws and re-checks the scene.

04Put it on a page

Your agent usually does this for you. Copy the runtime and the scene into your static folder and add a tag. Size it with CSS.

<stick-scene scene="learn-fractions" play="view"
  style="height: 230px"></stick-scene>

<script src="/scenes/stick.js" defer></script>
<script src="/scenes/learn-fractions.js" defer></script>

Load stick.js before any scene file. In React or Astro, add the scripts once in your layout and use the tag anywhere.

05Options

AttributeWhat it does
sceneThe id the scene registers.
play="view"Plays once when half of it scrolls into view, then on click. The best default.
play="click"Waits for a click or Enter.
play="hover"Loops while the mouse is over it. On touch screens, a tap plays it.
play="loop"Plays forever. Use it for loading states, and sparingly.
play="idle"Never plays the action, only the quiet idle.
no-floorDrops the grey band under the ground line, for plain white pages.
no-groundDrops the ground line too.
zoomScales the drawing inside its box. Default 1.
labelWhat a screen reader hears. Defaults to the scene's own sentence.

06Questions

Does it need a library or a build step?

No. The runtime is one plain JavaScript file that defines the <stick-scene> tag. Each scene is one more file.

Is it accessible?

The skill writes a sentence for screen readers into each scene. Scenes can be played with the keyboard, and show one still frame when the visitor prefers reduced motion.

Will lots of scenes slow the page down?

Scenes that are off screen don't draw at all, and the idle is cheap. This site runs more than forty on one page.

Can it match my brand?

Ask for your colours in the scene, or swap palette colours for the whole page with STICK.theme({ butter: '#…' }).

Can I use a scene from the gallery?

Yes. Open any scene in the gallery and copy its code. The files are in the skill's examples folder.

What does it cost?

Nothing. The skill is MIT licensed. Your agent's usage is the only cost.
